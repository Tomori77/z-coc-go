第一章：云端接入

⚠️ 核心警告：不要让您的理智（数据）烟消云散

如果您未在「设置中心」注册并登录账号，调查员、跑团存档与创作记录将只保存在当前浏览器。清理站点数据、更换设备或使用隐身模式，都可能使这些本地档案无法找回。

手把手操作指引：

  • 1

    点击左侧边栏最下方的 个人信息区域 或直接进入设置。

  • 2

    找到标有 “云端节点连接状态” 的面板，点击橙黄色的「接入云端」按钮。

  • 3

    完成注册并登录后，系统会自动拉取云端档案，并在数据变化后同步调查员、跑团存档、异闻创作与必要设置。API Key 仍只保存在当前浏览器。

第二章：设置中心与私有服务

1. 云端与联机使用自建服务

1.3.0 延续自建 PHP/MySQL 架构，不依赖 Supabase 实时连接。只要服务器支持 PHP 与 MySQL，就可以使用项目内置的 room_api.php、db_api.php 和 library_api.php。多人房间采用普通 HTTP 轮询同步，适合没有常驻进程权限的部署环境。

部署要点： 将源码上传到虚拟主机，复制 config.example.php 为 config.local.php，填入数据库账号、库名和允许访问的域名。

安全提醒： config.local.php 只放服务器，不要提交到公开仓库。

2. 接入 Nai2API 头像生成

进入「设置中心」的「头像生图配置」，填写您自己的 Nai2API 服务地址与用户密钥。地址可以只填域名，例如 https://your-domain.com，系统会自动拼接为 /generate 直链。

  • 自定义 URL / Key

    支持 STA1N 用户密钥，也支持带模板的兼容接口，例如 {prompt}、{token}、{model}。

  • 画师串预设

    内置 2.5D唯美风、韩漫小清新风、本子动漫风、GalGame风、动漫风（旧），也可以选择「自定义」后手写自己的质量前缀。

3. 配置私有模型链路

在「API 连接与服务」中选择提供商预设，或填写自己的 OpenAI 兼容地址。主叙事、辅助任务与快速响应模型可以分别配置；刷新模型列表后可直接选择服务端返回的模型。

桌面端

设置采用宽屏双列网格；高级选项、环境留声机、空间管理与功能开关会成对排列，减少无效留白。

移动端

设置首页只显示模块目录。点击模块进入详情，使用顶部返回按钮回到目录，无需在一张超长页面中反复滚动。

第三章：指令与侧边栏

1. 快捷调查员面板

在跑团过程中，点击屏幕右上角的 「👤小人图标」。您可以查看实时更新的属性表。重点：不需要打字！ 只需直接点击面板上的数值（如“侦查 70”），系统会自动在下方的对话框中填入标准指令。您只需按下回车即可发起检定。

2. 正确的检定语法

若手动输入，格式如下。若格式不规范，守秘人（KP）将无法识别您的动作：

.ra [检定项] [空格] [动作描述/RP]
示例：.ra 侦查 我屏住呼吸，扫视黑暗的走廊尽头

虽然动作描述可以省略，但我们强烈建议您写上一句，这能让 AI 守秘人给出更具代入感的反馈。

第四章：记忆回廊

1. 整理与文件夹

当存档堆积如山时，点击界面右上角的 「⚙️ 编辑/整理」 模式。在此模式下，您可以点击「新建文件夹」标志。您可以给文件夹命名（例如“阿卡姆编年史”），然后点击每一条存档右侧的“移动图标”，将其归类到对应位置。

2. 存档的生命周期

  • 导出存档

    点击存档卡片上的下载图标，可将其导出为 JSON 文件。这在进行大规模版本迁移或手动备份时非常有用。

  • 删除文件夹

    删除文件夹时，系统会询问您是“仅解散文件夹（存档放回根目录）”还是“连同内部存档一并抹除”。请谨慎操作。

第五章：异闻酒馆

在这里，枯燥的判定记录将被重塑。以下是创作一篇长篇报告的步骤：

I.

导入底本

点击上传框，选择您从“记忆回廊”导出的 JSON 存档文件。系统会自动读取其中的所有对话脉络。

II.

风格秘方

您可以指定“洛夫克拉夫特式”、“现代惊悚”或“调查员第一人称日记”等风格。选择不同的视角将产生截然不同的文学效果。

“老板，把这段经历写进书里吧。”

点击「开始创作」后，AI 将进入沉浸式撰写模式。完成后，您可以将其“收藏”到本页面的“藏书阁”中，或直接下载为 Word (DOCX) 或 Markdown 格式分享给其他同伴。

第六章：环境留声机

设置中心的「环境留声机」负责整个站点的背景声场。系统默认歌单包含 2.5 分钟版「雨夜（街巷）」，首次进入时会尝试以单曲循环播放。

播放模式

支持列表循环、顺序播放、随机播放与单曲循环；也可以添加本地 MP3、OGG 或 WAV 到当前浏览器歌单。

浏览器自动播放限制

若浏览器阻止自动播放，完成一次点击或触摸后音乐会继续启动。音量、开关与播放模式会保存在当前浏览器。

第七章：多人联机与同伴

这不仅仅是好友系统，更是多人联机的桥梁：

建立连接： 每一个调查员都有一个唯一的 UUID（可在侧边栏底部复制）。输入同伴的 ID 即可发送链路申请。建立好友关系后，您可以实时查看对方的在线状态及当前所在的探险房间位置。

快速集结： 在聊天过程中，您可以随时打开多人模式，直接对正在线上的好友发起“战友召集（邀请）”。对方会收到一条跨宇宙通知，点击即可穿越到您的探险房间中。

第八章：调查员档案

创建您的化身

点击「+ 创建调查员」按钮。在这张沉重的卷宗上，您可以定义：

  • 基础属性（手动输入或点击「骰子图标」进行圣洁的投掷）
  • 头像图片（支持拖拽或选择上传）
  • 角色背景与初始资产
导出 PNG 实体卡 导出 JSON 数据 角色卡模板复用

第九章：密大图书馆

借阅模组

在图书馆的海量书架上，您可以按照标签（现代、维多利亚、民俗等）进行筛选。点击任何一个模组卡片并选择「借阅模组」。该模组会自动同步到您的“仪式准备”列表中，等待开启。

贡献馆藏

如果您是一位博学的守秘人，可以点击上方状态栏的「创作」。您可以上传自己的剧本、设定封面和标签。审核通过后，全球各地的调查员都能借阅到您的杰作。

第八章：命运天平 (Scales of Fate)

在正式开启调查前，命运的权衡不可或缺。点击侧边栏的「命运天平」图标进入评估室。

模组情报汇聚

点击「寻获模组卷宗」上传您的剧本。系统支持增量上传：您可以先后上传正文、NPC表、以及模组相关的插图。AI 视觉会自动转译图像中的氛围信息，使评估结果更客观。

调查员评估

您可以从现有档案库选择调查员，也可以直接通过「寻获新调查员」入口拖入其他地方导出的 JSON 角色卡。AI 将为您提供详尽的适配度诊断（等级 S 至 D）。

小提示： 如果您暂时没有合适的调查员，可以使用「初始创建建议」模式，AI 会基于当前模组背景为您推荐最契合的属性分配与职业方向。
